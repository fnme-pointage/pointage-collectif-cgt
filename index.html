Liste type

Cette liste type sert de base à la création de chaque nouvelle unité. Tu peux la modifier seule ou appliquer les codes ajoutés ou modifiés à toutes les unités actives avec la case ci-dessous. Pour modifier une seule unité sans toucher à la liste type ni aux autres unités, sélectionne son nom dans « Catalogue à modifier » ci-dessus. Les pointages enregistrés et les mois fermés sont conservés.

Modifie les codes, les libellés ou les documents de référence. Décoche « Actif » pour retirer un code des nouvelles saisies, selon le périmètre choisi ci-dessous.

Si tu décoches cette option, seule la liste type des futures unités est modifiée. Les listes des unités existantes ne sont pas remplacées.

Enregistrer les modifications nationales sauvegarde tes changements et les applique aux unités si l’option correspondante est cochée.

Recharger la liste type affiche la dernière version enregistrée. Exemple : si ton compte est ouvert sur ton ordinateur et ton téléphone, une modification enregistrée sur le téléphone n’apparaît pas automatiquement dans la page déjà ouverte sur l’ordinateur. Clique sur « Recharger la liste type » pour la récupérer. Cela peut aussi arriver entre deux onglets du même navigateur.

Si tu essaies d’enregistrer une ancienne version, l’application bloque l’enregistrement pour éviter d’écraser une modification plus récente et te demande de recharger. Si tu as des modifications non enregistrées, une confirmation apparaît avant de les abandonner. Recharger ne remet pas la liste d’origine et ne modifie pas les catalogues des unités.

Catalogue de l’unité

Le catalogue de chaque unité est initialisé à partir de la liste type. Tu peux ensuite adapter les codes, les libellés et les documents aux besoins de ton unité. Sa liste en vigueur est proposée à tous ses utilisateurs, y compris aux nouveaux inscrits, selon le mois choisi. Depuis cet onglet, les modifications concernent uniquement cette unité et ne changent ni la liste type ni les autres unités. Les ajouts ou modifications de codes nationaux pour toutes les unités se font depuis ADMIN.
Depuis ADMIN, tu modifies uniquement le catalogue de l’unité sélectionnée. Choisis le mois d’application, puis enregistre. Les autres unités et la liste type des nouvelles unités ne changent pas. Pour modifier la liste type ou appliquer des changements à toutes les unités, sélectionne « Liste type des nouvelles unités » dans le menu.

Les modifications s’appliquent aux mois ouverts à partir de cette date, y compris aux années futures. Les mois fermés et les pointages déjà enregistrés conservent leurs références d’origine.

Appliquer les modifications aux unités :

Décoche « Actif » pour retirer un code des nouvelles saisies. Pour corriger un libellé, modifie sa ligne avec la date d’application souhaitée.

Utilisateurs

La vue ADMIN affiche tous les comptes. Les autres unités affichent uniquement leurs utilisateurs. Les inscriptions personnelles arrivent dans ADMIN et doivent être affectées puis activées. Les comptes créés ici par invitation sont directement rattachés à l’unité choisie, avec le profil autorisé. La colonne « Unité demandée » concerne les inscriptions personnelles.

Créer un utilisateur

Une invitation sera envoyée par e-mail. La personne choisira son propre mot de passe.

Historique des transferts entre unités

Transférer un utilisateur vers une autre unité

Le transfert est immédiat. Les pointages antérieurs restent dans leur unité d’origine. Si cette personne a déjà pointé pendant le mois en cours, le transfert sera refusé jusqu’au début du mois suivant.

Messages flash

Depuis Admin, tu peux publier un message national ou ciblé sur une seule unité. Les utilisateurs reçoivent les messages nationaux et les messages de leur unité.

Les dates et heures sont affichées dans le fuseau horaire de ton appareil.

Les mails sont envoyés individuellement depuis fnme.pointage@gmail.com aux utilisateurs actifs dont l’adresse est confirmée au moment de la création. Si le message est programmé, les envois commencent au début de l’affichage. Une seule reprise est prévue après l’envoi initial en cas d’échec, pendant la période de diffusion.

Messages publiés et programmés

Admin peut consulter et arrêter tous les messages. Dans l’espace d’une unité, seuls ses propres messages sont gérés. Arrêter un message interrompt son affichage et les e-mails restant à envoyer, mais ne rappelle pas les e-mails déjà expédiés.
