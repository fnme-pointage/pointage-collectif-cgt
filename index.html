Mon pointage

0,00 h

Ouvre la liste déroulante pour consulter les codes puis sélectionne un code et renseigne les heures.

En cas d’erreur sur une saisie déjà enregistrée, corrige la ligne concernée, puis clique à nouveau sur « Enregistrer mes données » pour sauvegarder la correction.

Important : l’enregistrement n’est pas automatique. Clique sur « Enregistrer mes données » avant de changer de mois, de te déconnecter ou de fermer l’outil.

Saisie en décimal/quantième : 7,25 ; 7,50 ; 7,75 ; etc.

Utilisateurs

La vue ADMIN affiche tous les comptes. Les autres unités affichent uniquement leurs utilisateurs. Tout nouveau compte arrive dans ADMIN. La colonne « Unité demandée » indique son choix à l’inscription : utilise « Modifier » pour choisir son unité affectée, puis active-le.

Le bouton « Exporter CSV » extrait le récapitulatif annuel par code de la personne pour l’année indiquée ci-dessus, dans son unité.
