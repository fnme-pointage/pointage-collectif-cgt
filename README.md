# Pointage Collectif CGT

Application de pointage collectif CGT, publiee avec GitHub Pages.

Site : https://fnme-pointage.github.io/pointage-collectif-cgt/

## Publication des modifications

La branche `main` est protegee par la regle GitHub `protection-main`.

Pour publier un correctif :

1. Creer une branche de travail a partir de `main`.
2. Modifier et verifier les fichiers sur cette branche.
3. Ouvrir une Pull Request vers `main`.
4. Fusionner la Pull Request une fois les verifications terminees.
5. Verifier que le deploiement GitHub Pages se termine avec succes.

Ce document a ete ajoute le 15 novembre 2026 pour verifier le fonctionnement des Pull Requests apres activation de la protection de `main`. Il ne modifie pas l'application.
